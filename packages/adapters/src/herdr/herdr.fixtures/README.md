# Recorded Herdr responses

`pnpm probe:herdr` writes redacted real responses here. Until a fixture set
exists for this host, `HerdrPiOrchestrator` reports itself as **experimental**
and the completion report must say so: mock acceptance alone is not evidence
that the live integration works.

Files are named after the command they came from, e.g. `workspace-create.json`.
Paths and identifiers are redacted before they are written.
